# Demo1 设计方案：肉鸽卡牌自走棋

## 1. 核心玩法 (Core Loop)
- **游戏周期**：每天 6 回合 (Round)，循环进行
- **回合类型**：
    - **Round 3**：野怪战（对战野怪）
    - **Round 6**：最终战（对战玩家投影）
    - **其余轮次（1,2,4,5）**：经营轮（商店、打工、宝箱）
- **血量与胜负**：
    - **局内血量 (HP)**：每回合开始时自动回满。战斗中 HP 归零则战斗失败
    - **声望 (Prestige)**：初始 20，归零则游戏结束（失败）

## 2. 胜负条件
- **胜利**：进度 Progress ≥ 10
- **失败**：声望 Prestige ≤ 0

## 3. 战斗结算规则
### 野怪战（Round 3）
- **胜利**：获得奖励
- **失败**：无任何影响

### 最终战（Round 6）
- **胜利**：Progress + 1
- **失败**：Progress - 1，且 Prestige -= Day

## 4. 流程状态机
```
SelectionProcedure (选择态)
    ↓
EventProcedure (事件态)
    ├── ShopProcedure (商店)
    ├── WorkProcedure (打工)
    ├── TreasureProcedure (宝箱)
    └── BattleProcedure (战斗)
    ↓
RewardProcedure (结算态)
```

### 每轮流程
```
Day 1:
  Round 1 → Selection → Event → Reward
  Round 2 → Selection → Event → Reward
  Round 3 → Selection → 野怪战 → Reward
  Round 4 → Selection → Event → Reward
  Round 5 → Selection → Event → Reward
  Round 6 → Selection → 最终战 → Reward（扣声望/加进度）

Day 2: ... 循环
```

## 5. 事件规则

### 商店 (Shop)
- 货架：3 个商品
- 刷新：每进商店只能刷新 1 次，费用 2 元
- 离开后重新进入商店刷新次数重置

### 打工 (Work)
- 奖励：钱 + 附加（新卡/经验/纯钱）
- 玩家选择后领取奖励

### 宝箱 (Treasure)
- 奖励：卡 + 技能
- 玩家选择后领取奖励

### 战斗 (Battle)
- 自动战斗，卡牌按 CD 轮流释放技能
- 战斗结束后根据回合类型处理结算

## 7. 卡牌系统 (Card System)
- **尺寸规则**：小(1格)、中(2格)、大(3格)。
- **卡牌分类**：
    - **主动卡**：带冷却 (CD) 条，归零释放伤害/盾/毒。
    - **被动卡**：监听特定标签触发。
- **品质与合并 (Merging)**：
    - 品质等级：青铜 -> 白银 -> 黄金 -> 钻石。
    - **规则**：仅在商店**购买**时触发合并。
    - **不连跳**：合并出的卡不再次检查合并。

## 8. 核心数据
| 字段 | 初始值 | 说明 |
| :--- | :--- | :--- |
| Progress | 0 | 进度（胜利条件：≥10） |
| Prestige | 20 | 声望（失败条件：≤0） |
| Day | 1 | 天数（失败时扣除声望） |
| Round | 1 | 回合（1-6 循环） |
| Gold | 10 | 金币 |
| Exp | 0 | 经验（8 升级，扩容 +2 格） |
| MaxSlots | 4 | 最大出战位（上限 10） |
